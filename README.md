# SejukServis — Prototipe Sistem Informasi Servis AC (UMKM)

Prototipe web tugas Sistem Informasi Bisnis. Lihat: https://fama064.github.io/sejuk-servis-web/

- index.html : kerangka halaman
- app.css : gaya visual (mobile-first)
- app.js : data simulasi + logika 3 peran (pelanggan, admin, teknisi)
- Konfigurasi notifikasi Telegram ada di CONFIG pada app.js (botToken + chatId dari @BotFather).

Nama usaha, harga, kontak, dan testimoni adalah data contoh untuk keperluan tugas kuliah.
